## 风险与约束

### 高风险项
1. **时间风险**：P0 功能复杂，预计 18-20周（约 4-5个月）
2. **Web IndexedDB 限制**：浏览器配额、驱逐风险需充分测试
3. **调度算法复杂度**：幂等性、跨日、再错需大量边界测试
4. **备份恢复安全**：原子替换、失败回滚需失败注入测试

### 技术约束
1. **当前环境无法充分测试**：
   - Android/iOS 构建需要完整 SDK
   - Web 离线需要真实浏览器环境
   - 图片处理需要真实相机/选图
2. **CI 环境限制**：
   - 无 libsqlite3.so（Flutter 集成测试）
   - 无浏览器环境（Web 冒烟测试）

### 缓解策略
1. 分阶段增量交付，优先核心调度和数据安全
2. 充分单元测试，模拟边界场景
3. 明确列出未验证项，不虚报进度
4. 保留可复核输出（测试日志、覆盖率报告）
